Scenes

Add images in the order you want them. Each one drifts slowly — that movement is what stops a slideshow looking like a slideshow.

Format

Recording is real time. A 30-second video takes about 30 seconds to record, because the browser is capturing the canvas as it plays. Keep it under a minute or two on a phone.

Script

Type what you want said. The device speaks it with its own installed voices — no key, no card, no upload.

Delivery

You can play it, not download it. Browsers deliberately give no way to save their speech output to a file — that would make free voice cloning trivial. To get an audio file you need a speech service with an API, which is a different product.

Generated track

Made on the spot from oscillators and noise, then rendered to a real WAV you can keep. No samples, no licence, no upload.

Ingredients

This is synthesis, not a model. It composes from a scale and a pattern — which is why it works offline and costs nothing. A model that "makes music from a description" needs a hosted service, and those are not card-free.
